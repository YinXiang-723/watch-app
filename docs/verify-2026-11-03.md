## 踩到的两个坑（已绕过）

1. **`adb pull` 无法写入中文路径**：`cannot create 'E:\工作\...\screen.png': No such file or directory`。
   改用 `adb exec-out screencap -p` 捕获 stdout（由 PowerShell/Python 写文件），或把文件先拉到纯 ASCII 路径再复制。
2. **沙箱环境里 adb 启动失败**：`cannot open C:\Users\ASUS\adb.log: Permission denied`。
   把 `TEMP`/`TMP` 指向工作区目录（如 `.adtmp`）即可；在普通 cmd/PowerShell 里运行不受影响。
